# MeetingMind

## Memory-Powered Meetings

MeetingMind is an AI meeting preparation agent that remembers
important information from previous conversations and uses that
context to prepare users for upcoming meetings.

## Problem

Traditional AI assistants often treat every conversation as a
new interaction. Important preferences, concerns and commitments
can be lost between meetings.

## Solution

MeetingMind uses Hindsight as a persistent memory layer.

It remembers previous interactions and recalls relevant context
when preparing for a future meeting.

## How It Works

User Interaction
       ↓
MeetingMind
       ↓
Hindsight Memory
       ↓
Persistent Context
       ↓
Meeting Preparation
       ↓
Personalized Meeting Brief

## Example

First interaction:

"Rahul prefers quarterly billing and is concerned about API security."

Second interaction:

"Rahul asked us to send the security documentation before the
next meeting."

MeetingMind then recalls this context and produces:

- Preferences
- Concerns
- Open Commitments
- Previous Discussions
- Suggested Talking Points

## Tech Stack

- React
- Vite
- Node.js
- Express.js
- Hindsight
- JavaScript

## Key Feature

The core of MeetingMind is persistent memory.

Instead of starting every meeting with an empty context,
MeetingMind retrieves relevant information from previous
interactions.
