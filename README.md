# MeetingMind 🧠

Memory-powered AI meeting preparation agent.

## Features

- Persistent conversation memory
- Contact-specific memory
- Meeting preparation
- Preference recall
- Concern recall
- Commitment recall
- Suggested talking points

## Tech Stack

- React + Vite
- Node.js
- Express.js
- Hindsight

## Architecture

React
↓
Node + Express
↓
Hindsight
↓
Contact-specific persistent memory
↓
Meeting Brief

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```
```backend
cd backend
npm install
node server.js
```
